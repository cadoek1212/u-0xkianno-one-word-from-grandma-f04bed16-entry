One Word From Grandma — an entry for make.fun's One Word From Grandma bounty ($5 in USDC). The program scores 25 candidate words against the judge's five criteria and writes the winner — the single word a grandma would type about AI — to /output/entry.txt. Winner: "Al". Grandma types "Al": she thinks the AI is a nice man named Al, or she simply mistyped AI.
